Fundamentos técnicos y conceptuales aplicados en el desarrollo de la graficación por computadora.

1. La etiqueta HTML <canvas> y sus contextos de renderizado 2D

La etiqueta <canvas> es un elemento fundamental de HTML5 que actúa como un contenedor gráfico rectangular en blanco dentro de una página web. Por sí sola, la etiqueta no puede dibujar ningún gráfico; funciona como una superficie de dibujo programable sobre la cual se pueden renderizar elementos visuales mediante lenguajes de secuencia de comandos, principalmente JavaScript.

Funcionamiento básico y coordenadas: El lienzo se define indicando sus dimensiones de ancho y alto (por ejemplo, 400x400 píxeles). Cada punto dentro de la superficie se maneja mediante un sistema de coordenadas cartesianas (x, y), donde el origen (0, 0) se ubica por defecto en la esquina superior izquierda.

El contexto de renderizado 2D (getContext('2d')): Para poder trazar elementos en el lienzo, el navegador necesita invocar un objeto de contexto que provee todas las herramientas, métodos y propiedades de dibujo. Al solicitar el contexto bidimensional mediante JavaScript, se habilita una API nativa que permite:

  • Dibujar formas geométricas primitivas (rectángulos, círculos, arcos y trazos libres).
  • Gestionar colores de relleno y contorno (propiedades como fillStyle y strokeStyle).
  • Manipular directamente los mapas de bits y la rasterización de píxeles en pantalla.

2. Fundamentos de la librería p5.js en gráficos y animaciones

p5.js es una biblioteca de JavaScript orientada a la computación creativa que simplifica drásticamente el desarrollo de gráficos interactivos. Actúa como una potente capa de abstracción construida por encima de la API nativa del elemento <canvas> y su contexto 2D, permitiendo escribir código mucho más limpio, intuitivo y expresivo.

Los pilares fundamentales de p5.js utilizados en este portafolio comprenden:

  • Estructura de Ciclo de Vida (setup y draw): La función setup() se ejecuta una sola vez al cargar la página para inicializar el entorno y crear el lienzo mediante createCanvas(). Por su parte, la función draw() actúa como un bucle continuo (bucle de renderizado) que repite las instrucciones cuadro por cuadro, ideal para actualizar dinámicamente posiciones y animaciones.
  • Primitivas Geométricas Simplificadas: Proporciona funciones directas y legibles para el trazado de figuras, tales como ellipse(), rect(), triangle() y line(), recibiendo parámetros numéricos de posición y tamaño para construir composiciones complejas por superposición.
  • Control de Atributos Visuales y Estados: La gestión de colores y estilos se maneja de forma secuencial mediante funciones de estado como background() para limpiar y pintar el fondo, fill() para los colores internos de las figuras, y noStroke() para la eliminación de contornos.
